为什么写博客

把一件事讲清楚，比自己觉得懂了要难得多。写作会逼着你把模糊的地方补上—— 经常是写到一半才发现某个环节其实没搞懂，于是回去重看、重做实验。 所以这些文章对我来说首先是笔记，其次才算是分享。

这个站点是怎么做的

  • 文章是 Markdown 文件，放在 posts/ 目录里
  • 用 Python 脚本（约 500 行）一次性生成整站 HTML
  • 没有数据库、没有服务端、没有前端框架，纯静态文件
  • 托管在 GitHub Pages 上

这样做的好处是：打开速度快、几乎不可能被攻击、托管免费， 而且整站可以随时打包带走。
